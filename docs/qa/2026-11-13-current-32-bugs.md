Plist parsing and the existing deep-link declaration pass. Windows uses its existing native system dialog without this macOS bundle metadata.
- **28 — Cannot save a changed upstream format:** preserve saved credentials when changing the protocol at the exact same base URL and authentication mode. Moving hidden credentials to another URL or changing authentication mode remains rejected. Explicit protocol-bound imported key pools retain their existing constraints.
